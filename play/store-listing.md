### Full description

```text
Understand what your NAS is doing—not just whether it is online.

NAS Watchdog is an independent Android companion for a self-hosted NAS Watchdog server. Check processor and memory activity, detailed temperatures and cooling, btrfs storage and SMART health, network activity, and your actual Docker inventory from one clear dashboard.

FEATURES

• Live health overview with connection and last-update status
• CPU, resource, fan, and per-device temperature history
• Disk, pool, RAID, allocation, and SMART details
• Docker container health, resource use, and logs
• Network details and structured alert history
• Optional user-enabled background monitoring and notifications
• Last-known snapshot when a configured server is temporarily unavailable

Choose 5-minute, 1-hour, 6-hour, or 24-hour history ranges where data is available. Thermal views explain current readings and recent changes instead of inventing sensors your host does not expose.

No NAS Watchdog developer account, advertising SDK, or analytics SDK is required. Connection settings and recent telemetry stay on your device; connection requests go to the server you configure. Optional server-side webhooks and notification services are controlled by the server administrator.

REMOTE ACTIONS ARE OFF BY DEFAULT

The app can request confirmed container, scrub, or reboot actions only when the watchdog administrator has explicitly enabled those capabilities. They are operational tools, not automatic repairs. Never expose the server directly to the public internet; use a trusted LAN or VPN.

REQUIREMENTS AND COMPATIBILITY

A separately installed, compatible NAS Watchdog server is required; this app does not monitor a phone or operate as a standalone NAS. Android 8.0 or newer is supported. Available readings depend on the NAS model, operating system, kernel, connected devices, and permissions. Community compatibility information and installation instructions are available from the project website.

NAS Watchdog is independent and is not affiliated with, sponsored by, authorized by, or endorsed by Zettlab or any other NAS manufacturer. Zettlab and ZettOS are referenced only to describe compatibility with selected community-supported hardware. No manufacturer firmware or proprietary application is included.

Privacy policy: https://github.com/greyyk/nas-watchdog/blob/main/PRIVACY.md
Source and setup: https://github.com/greyyk/nas-watchdog
```
